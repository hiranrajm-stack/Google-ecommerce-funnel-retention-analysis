# Google E-Commerce Funnel & Retention Analysis

I wanted to find out where people actually drop off when shopping online, 
and whether they ever come back after their first visit. So I picked a 
real public dataset and dug into it using SQL, built a dashboard, and 
wrote a script that generates the business memo automatically using the 
Gemini API.

## Data
I used Google's own public GA4 e-commerce dataset in BigQuery 
(`bigquery-public-data.ga4_obfuscated_sample_ecommerce`). It has around 
4.3 million real, anonymized events from the Google Merchandise Store, 
collected over about 3 months. I chose this instead of a downloaded CSV 
because I wanted to practice querying data the way it actually sits in a 
company's database, not a spreadsheet.

## What I did
1. Wrote SQL in BigQuery to track the purchase funnel — how many people 
   viewed a product, added it to cart, started checkout, and actually 
   paid. All queries are in `queries/`.
2. Used SQL window functions to group users by the week they first 
   showed up, then checked how many of them were still active in the 
   weeks after — this is the cohort retention analysis.
3. Pulled the results into Power BI and built an interactive dashboard 
   so the findings are easy to look at, not just numbers in a query 
   result. That's in `dashboard/`.
4. Wrote a small Python script (`memo_generator.ipynb`) that sends my 
   findings to the Gemini API and writes back a business memo — so the 
   memo isn't something I typed out by hand, it's generated by the 
   script from the actual numbers. I did the analysis and figured out 
   what the numbers meant; the script's job is just turning that into 
   a clean write-up automatically.

## What I found
- Only 1.5% of people who view a product actually end up buying it
- 85% of people never even add the product to their cart — that's a 
  demand/merchandising problem, happening before anyone's decided to buy
- Of the people who do start checking out, 85% never finish — that's a 
  friction problem, since these are people who'd already decided to buy
- Only about 4% of new users come back the week after their first visit, 
  and this pattern holds across all 8 weeks I checked — so it's not a 
  one-off dip, it's how the site behaves consistently

## Tools I used
SQL (BigQuery/GoogleSQL, window functions), Power BI, Python, Gemini API

## What's in this repo
- `queries/` — all my SQL, in the order I built them
- `dashboard/` — the Power BI file and a screenshot of the dashboard
- `memo_generator.ipynb` — the script that calls Gemini to generate the memo (API key removed)
- `business_memo.md` — the memo itself, generated by the script from my findings
